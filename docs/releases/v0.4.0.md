# ADS-B Notifier v0.4.0

Released: 2026-09-08

Draft source: changes since `v0.3.0`.
- Roadmap: /Users/terryr/Documents/ryan-personal-vault/Projects/ADSB-Notifier/ADSB-Notifier Roadmap v0.4.0.md

ADS-B Notifier `v0.4.0` is a focused source-configuration cleanup after validating a real local tar1090/readsb feeder as a local receiver source.

## Highlights

- Removed the visible `Direct aircraft.json` source option from the Settings UI.
- Standardized new local aircraft JSON endpoints on `local_receiver` with `query: "url"`.
- Fixed stale backup source form state when switching away from local receiver URL/file mode.
- Added disabled-field styling and helper text for source controls that do not apply to the selected provider/query.
- Changed API default config seeding to use a local receiver URL source instead of legacy top-level `adsb_url`.

## Notes

- This release is config and UI cleanup only.
- Backend legacy `adsb_url` fallback and the worker `--adsb-url` override remain for older configs and development workflows.
- No custom binaries or release artifacts are expected beyond the normal GitHub source archives.

- Static/runtime checks before promotion: `python3 -m compileall -q adsb_notifier` and UI JS syntax checks -> passed.
