# ADS-B Notifier v0.3.0

Released: 2026-08-31

Draft source: changes since `v0.2.0`.
- Roadmap: /Users/terryr/Documents/ryan-personal-vault/Projects/ADSB-Notifier/ADSB-Notifier Roadmap v0.3.0.md

ADS-B Notifier `v0.3.0` improves release communication, notification editing, dashboard history, source visibility, and ADS-B source resilience while keeping the same local Kubernetes deployment model.

## Highlights

- Added a GitHub release-notes workflow for stable minor releases.
- Redesigned the Notifications page so one provider is edited at a time, with enabled providers prioritized.
- Added notification template previews for Email, Pushover, and Twilio, including rendered HTML email preview support.
- Added API-backed recent-match export for JSON and CSV, including selected-match and multi-match dashboard export flows.
- Added category exclusions for global and per-rule alert filtering.
- Improved dashboard map framing and fit behavior.
- Added PVC-backed source health trend events with configurable retention and a dashboard trend chart.
- Added local receiver source support through URL or file-backed fixture data.
- Added primary-to-backup ADS-B source failover for unavailable, rate-limited, and stale primary source states, with configurable primary retry timing.
- Repaired the local development `kill-local` helper.

## Notes

- No custom binaries or release artifacts are expected beyond the normal GitHub source archives.
- Patch/checkpoint versions and release candidates are summarized here only when they contribute to the stable minor release.
- Local receiver file mode is primarily for fixture-driven development and validation.
- Local receiver hardware validation and failover/failback soak should be confirmed during the `0.3.0-rc.1` soak before stable promotion.
