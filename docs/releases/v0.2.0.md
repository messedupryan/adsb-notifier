# ADS-B Notifier v0.2.0

Released: 2026-08-29

ADS-B Notifier `v0.2.0` makes the app easier to operate day to day by reducing alert noise, speeding up rule management, and improving dashboard troubleshooting while keeping the same local Kubernetes deployment model.

## Highlights

- Added per-rule quiet hours, including timezone-aware quiet windows and suppressed-notification status in recent matches.
- Added global and per-rule alert exclusions for tail numbers, ICAO hex IDs, callsigns, and aircraft types.
- Added rule search, rule type/status filters, explicit multi-select, and bulk enable/disable actions.
- Grouped repeated dashboard matches by aircraft and rule while preserving each underlying event.
- Added recent match details with key aircraft fields and a collapsible normalized payload.
- Added recent match filters for event type, rule, notification provider, notification status, and aircraft search.
- Added source-specific health status for the configured ADS-B provider on the dashboard and in source settings.
- Added `make release-rc` for clean-worktree release-candidate versioning, image build/push, Helm deploy, and rollout.

## Notes

- Recent-match filtering still uses the current in-memory recent status window; persistent multi-day history remains deferred.
- Category exclusions are intentionally deferred to a later release.
- Normal deployment continues to use explicit version tags for worker, API, UI, and Helm chart versions.

## Validation

- Full test suite passed before the stable cut.
